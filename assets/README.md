# AIMJWEB Original Assets

These standalone SVG files were created specifically for the AIMJWEB GitHub
profile shrine. They use only embedded vector shapes, patterns, and system-safe
font fallbacks.

| File               | Purpose                             |
| ------------------ | ----------------------------------- |
| `aimj-banner.svg`  | Full-width AIMJWEB shrine header    |
| `lace-divider.svg` | Pastel lace section divider         |
| `chibi-mascot.svg` | Original robot bunny profile mascot |
| `sidebar-icon.svg` | Retro pixel-style mail icon         |
| `footer.svg`       | Gingham visitor footer              |
| `pixel-button.svg` | Small AIMJWEB navigation button     |

No file requires JavaScript, remote images, external CSS, or external fonts.
