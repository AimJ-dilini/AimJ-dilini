# AIMJWEB Asset Guide

The profile README references these replaceable, user-owned artwork files:

| File               | Suggested size | Purpose                          |
| ------------------ | -------------: | -------------------------------- |
| `header.png`       |   720 x 180 px | AIMJWEB logo or pastel masthead  |
| `banner.gif`       |   820 x 260 px | Main shrine banner               |
| `lace-divider.png` |    720 x 40 px | Cream or pink lace divider       |
| `divider-pink.gif` |    720 x 30 px | Small pixel-art section divider  |
| `chibi-icon.png`   |   240 x 240 px | Original profile avatar or chibi |
| `sidebar-icon.png` |   180 x 180 px | Small sidebar pixel icon         |
| `footer.gif`       |   720 x 120 px | Lightweight animated footer      |

Use artwork you created, commissioned, licensed, or otherwise have permission to
publish. Keep GIFs small so the profile remains fast to load. The README's alt
text provides a readable fallback until each asset is added.
