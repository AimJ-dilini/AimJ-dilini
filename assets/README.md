# Dilini Shrine Assets

These standalone SVG files were created specifically for the Dilini GitHub
profile shrine. They use only embedded vector shapes, patterns, and system-safe
font fallbacks.

| File                | Purpose                              |
| ------------------- | ------------------------------------ |
| `aimj-banner.svg`   | Soft anime-web shrine header         |
| `profile-frame.svg` | Empty polaroid-style profile frame   |
| `gallery-frame.svg` | Reusable project gallery frame       |
| `lace-divider.svg`  | Thin pixel lace section divider      |
| `sidebar-icon.svg`  | Tiny pixel flower                    |
| `footer.svg`        | Soft checkered visitor footer        |

No file requires JavaScript, remote images, external CSS, or external fonts.
