# AIMJWEB Poster Assets

These SVGs are original artwork created for the Dilini GitHub profile shrine.
They use only embedded vector shapes, patterns, and system-safe font fallbacks.

| File | Purpose |
| --- | --- |
| `aimj-hero-poster.svg` | Main anime poster hero banner |
| `section-divider.svg` | Thin vintage section divider |
| `profile-poster-card.svg` | Framed profile poster card |
| `project-panel.svg` | Reusable project panel frame |
| `footer-strip.svg` | Printed footer strip |

No file requires JavaScript, remote images, external CSS, or external fonts.
